系统代理—

打开后浏览器、IDM 等遵守系统代理的程序立刻生效；关闭会还原成你原来的设置。
系统代理指向了一个没有服务的端口 —— 浏览器会把所有请求发给一个没人应答的地址， 表现就是网页全部打不开（哔哩哔哩、百度……全都一样）。
这通常是上次异常退出留下的。没有备份文件，无法还原成开启加速器之前的样子， 但可以先把代理关掉恢复上网。

怎么用？（点击收起 / 展开）
1. 浏览器 / IDM / aria2
在概览页打开「系统代理」开关，或手动把 HTTP 和 HTTPS 代理都指向 —。 aria2 命令行加：--all-proxy=http://127.0.0.1:8899。

2. 判断 IPv6 到底有没有用
在测速页填同一个下载地址，先看 IPv6 一栏、再看 IPv4 一栏的实测吞吐。 v6 快才值得用 v6，很多国内 CDN 的 v6 路径确实更空，但也有反过来的时候。

3. 为什么不改 hosts 也能生效
代理模式在 TCP 连接层就把目标换成了优选 IP，域名（SNI/Host）保持不变， 所以既能命中正确的 CDN 节点，又不需要动系统文件、不需要管理员权限。

4. 游戏平台（Steam / Epic 等）
它们的下载器不读系统代理，只能用 hosts 模式 —— 需要管理员权限启动本程序。

5. 拉黑某个 IP
路由表里点「拉黑」，之后该 IP 不再参与竞速，适合处理某个走不通的节点。
