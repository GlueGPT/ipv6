自定义域名（hosts）可选 · 需要管理员

上面的模式是预置清单。这里给任意域名做优选并写入 hosts。 只写入一段带标记的区块，可以一键完全还原，不会动你原有内容。
怎么用？（点击展开）
1. 浏览器 / IDM / aria2
把 HTTP 和 HTTPS 代理都指向 —。 aria2 命令行加：--all-proxy=http://127.0.0.1:8899。 代理会自动把每个域名的连接换成优选后的 IP，并且不影响 TLS 证书校验。

2. 判断 IPv6 到底有没有用
在上面的输入框里填同一个下载地址，先看 IPv6 一栏、再看 IPv4 一栏的实测吞吐。 v6 快才值得用 v6，很多国内 CDN 的 v6 路径确实更空，但也有反过来的时候。

3. 为什么不改 hosts 也能生效
代理模式在 TCP 连接层就把目标换成了优选 IP，域名（SNI/Host）保持不变， 所以既能命中正确的 CDN 节点，又不需要动系统文件、不需要管理员权限。

4. 拉黑某个 IP
路由表里点"拉黑"，之后该 IP 不再参与竞速，适合处理某个走不通的节点。
